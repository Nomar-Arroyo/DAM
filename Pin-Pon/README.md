# Pin-Pon

Juego de pin pon para terminal hecho en Dart. Version 1.1.0

## Caracteristicas

- Menu inicial con modos de juego
- Jugar contra otra persona (W/S y I/K)
- Jugar contra la IA
- Sesion de Retos (4 retos desbloqueables)
- Seleccion de dificultad: Facil, Medio, Dificil
- Velocidad de la pelota progresiva segun el puntaje
- Movimiento fluido de paletas
- Pausa de partida

## Controles

| Tecla | Accion                |
|-------|-----------------------|
| W / S | Mover paleta J1       |
| I / K | Mover paleta J2       |
| P     | Pausar partida        |
| Q     | Salir                 |

## Ejecutar

```bash
dart run bin/pin_pon.dart
```
